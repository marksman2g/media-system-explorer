OFFLINE USE
The explorer contains its own HTML, styles, scripts, text and source register. It does not fetch a remote library, stylesheet, font or API. Its search, expansion, full-report view and calculator do not need the internet. Source website links require internet. Linked local audio/PDF files should stay in the same extracted folder.

Normal browsers can open local HTML; an employer-managed browser may prohibit file URLs or scripts. See QA_Notes.txt for the test environment's local-file policy limitation. This does not require a hosted version or subscription.

WHAT THE PACKAGE COVERS
Two equal architecture paths: external access and owning/administering media. Twenty acquisition routes; six torrent sources with integration and rights limits; ten Flix-like playback alternatives; ten NAS models with exact/alternative bay labels; expansion, 10Gb networking, five-viewer scenarios, PIA, media-server platforms, optional automation, and pass/fail acceptance tests.

IMPORTANT SCOPE
This is the completed research/design package, not a deployed streaming service. No hardware was purchased, no provider accounts were provisioned, no private tracker access was obtained, and no torrent download was performed. Exact drive compatibility, provider permissions and real-device workload tests remain deployment gates. Prices/stock/source availability can change. An active integration definition is not an uptime or content-licensing guarantee.

CORE DECISION
Fix independent provider authorization before paying for replacement player activations. Buy storage only for files you choose to keep. Grow through one catalog over separate protected storage systems rather than assuming linked NAS units merge into one fault-proof pool.
